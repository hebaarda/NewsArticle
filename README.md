# Evaluate a News Article with NLP

A single-page web application developed in 08/2024 as part of the **Udacity Front-End Web Developer Nanodegree**.

The project allows users to enter a news article URL and analyzes its sentiment using **Natural Language Processing (NLP)** and the **MeaningCloud API**. The application displays results such as polarity, subjectivity, confidence, agreement, and irony.

### Technologies

* HTML
* JavaScript
* Node.js & Express
* Webpack
* Sass
* MeaningCloud API
